編集のみの動画で大切にしていること

  1. テキストは「ひと目で読める」短さに
    商品ページの動画は音なしで見られることも多いため、テキストの読みやすさが大切です。文字の大きさ、表示時間、配置を整えて、流し見でも伝わるように編集します。
  2. アニメーションで情報を整理
    イラストや図解のアニメーションを加えると、静止画だけの素材でも、使い方や特長を分かりやすく伝えられます。ポップな漫画風の演出にも対応しています。
  3. 商品画像と統一感を持たせる
    色味やフォント、テーマカラーを商品画像にそろえると、商品ページ全体に一体感が生まれます。ブランドの雰囲気を崩さない編集を心がけています。
  4. 短尺でもテンポよく
    動きや効果音のつけ方で、短い動画でも印象に残る仕上がりにします。広告用の短い尺への編集もご相談ください。

表現と審査について

編集のみの場合も、テロップの表現は審査の対象です。効果を断定する言葉や根拠のない最上級表現は否認されやすいため、審査に通りやすい表現に整えてお作りしています。審査エラーに伴う修正は、掲載まで無制限で対応します。

審査で引っかかりやすい表現の具体例は、こちらの記事で紹介しています。

よくある質問

スマホで撮った素材でも大丈夫ですか？

素材の明るさや手ブレの状態によって仕上がりが変わるため、まずは素材を拝見したうえでご提案します。

商品画像だけで動画を作れますか？

はい。画像にアニメーションやテキストを組み合わせて、動きのある動画にお仕上げします。

あとから撮影を追加することはできますか？

素材が足りない場合は、撮影込みのプランへの変更もご相談いただけます。
